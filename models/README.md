# models/

Generated by `python -m src.train_model ...` (git-ignored):

- `url_model.joblib` - TF-IDF (char 3-5-grams) + logistic regression pipeline. Label 1 = phishing.
- `url_model.meta.json` - model version, scikit-learn version, SHA-256 of the artefact, data provenance, split sizes and
  validation-fitted thresholds (`t_hi`, `t_low`).
- `dataset_provenance.json` - copy of the data provenance block.

`joblib` files are pickles. The loader refuses a file whose SHA-256 or scikit-learn version does not match the metadata.
Never load a model file from an untrusted source.

If no model exists, the app trains a small **synthetic demo model** on first start (a few seconds) and labels it as such.
